# 🚗 EV Analytics Dashboard

## 📊 Electric Vehicle Analytics Dashboard | Power BI

An interactive Power BI dashboard designed to analyze electric vehicle data and explore EV trends, brands, locations, pricing, and other key insights.

---

## 🎯 Project Objective

The objective of this project is to transform raw electric vehicle data into an interactive dashboard that provides clear and useful insights through data cleaning, transformation, DAX calculations, and visualization.

---

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculations
- **Microsoft Excel** – Dataset preparation

---

## 📌 Key Analysis

- 🚘 Total EV analysis
- 🏷️ Brand-wise analysis
- 📍 City and state-wise analysis
- 💰 Price analysis
- 📈 EV trends and growth
- 🔎 Interactive slicers and filters

---

## 📈 Dashboard Features

- Interactive Power BI visuals
- KPI cards
- Dynamic filtering
- Trend analysis
- Brand and location comparisons
- User-friendly dashboard design

---

## 🧹 Data Preparation

Data was cleaned and transformed using Power Query, including:

- Handling missing values
- Removing unnecessary data
- Transforming data types
- Preparing fields for analysis
