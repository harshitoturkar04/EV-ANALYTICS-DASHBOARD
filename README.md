# EV-ANALYTICS-DASHBOARD
🚗 Electric Vehicle Analytics Dashboard | Power BI
An interactive Power BI dashboard designed to analyze and visualize electric vehicle data, helping users explore EV trends, brands, locations, pricing, and other key business insights.

📊 Dashboard Preview
EV Dashboard

🎯 Project Objective
The objective of this project is to transform raw electric vehicle data into an interactive dashboard that provides clear and useful insights through data cleaning, transformation, DAX calculations, and visualization.

🛠️ Tools & Technologies
Power BI – Dashboard development & data visualization
Power Query – Data cleaning and transformation
DAX – Measures and analytical calculations
Microsoft Excel – Dataset and data preparation
📌 Key Analysis
The dashboard provides analysis such as:

🚘 EV count and overall statistics
🏷️ Brand-wise EV analysis
📍 City/State-wise analysis
💰 EV price analysis
📈 EV growth and trend analysis
🔋 EV-related performance analysis
🔎 Interactive filtering using slicers
📈 Dashboard Features
Interactive Power BI visuals
Dynamic slicers and filters
KPI cards for important metrics
Trend analysis
Comparative analysis across brands and locations
User-friendly dashboard layout
🧹 Data Preparation
The dataset was processed using Power Query to:

Remove unnecessary/duplicate data
Handle missing values
Transform columns and data types
Create clean fields for analysis
Prepare the dataset for Power BI visualization
🧮 DAX
DAX measures were created to calculate important KPIs and analytical metrics used throughout the dashboard.

Example:

Total EVs = COUNTROWS(EV_Data)
